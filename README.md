# TASK-11
Thala 7 Sneaker Store

CSS Mini Project

Thala 7 Sneaker Store is a simple sneaker-selling web page designed using HTML and CSS. The project contains a landing page, product display, shopping cart, and payment section.

Features

- Landing Page
- Header and Navigation Bar
- Hero Section
- Shop Now Button
- Service Overview
- Product Display Section
- Product Image Gallery
- Product Details
- Price and Discount
- Quantity Section
- Add to Cart Button
- Shopping Cart Section
- Coupon Code Section
- Order Summary
- Payment / Checkout Section
- Card, Crypto and Bank Payment Options
- Responsive Design
